# 웨딩폼

결혼식 이벤트 영상을 QR로 하객에게 판매하고 이벤트를 제공하는 플랫폼.

GitHub: https://github.com/nan29077/weddingform

## 실행 (Windows PowerShell)

`start.bat`을 더블클릭하면 필요한 패키지를 설치하고 3046 포트의 미리보기 서버를 실행한 뒤 브라우저를 엽니다.

```powershell
cd "E:\프로젝트\웨딩폼"
.\start.bat
```

미리보기: http://localhost:3046

## 스택
- Next.js 15 (App Router) · TypeScript · Tailwind CSS v4
